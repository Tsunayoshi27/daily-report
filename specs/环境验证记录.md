## 3. API 只读接口调用验证

### 3.1 GitHub API — 读取用户仓库列表

```powershell
Invoke-WebRequest -UseBasicParsing -Uri "https://api.github.com/user/repos?per_page=3" `
     -Headers @{"Authorization"="Bearer $env:GITHUB_PAT"}
```

预期结果：返回 HTTP 200，Body 为 JSON 数组，包含个人仓库列表。

**实测结果**：
- HTTP 状态码：200 OK
- 是否返回预期 JSON：是
- 备注：成功获取个人仓库列表（Content 为 JSON 数组）

### 3.2 飞书 API — 获取 tenant_access_token

```powershell
$body = @{app_id=$env:FEISHU_APP_ID; app_secret=$env:FEISHU_APP_SECRET} | ConvertTo-Json
Invoke-WebRequest -UseBasicParsing -Uri "https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal" `
     -Method POST `
     -ContentType "application/json" `
     -Body $body
```

预期结果：返回 HTTP 200，Body 包含 `tenant_access_token`。

**实测结果**：
- HTTP 状态码：200 OK
- 是否获得 token：是（code=0, expire=7200）
- 备注：成功获取 tenant_access_token

### 3.3 SMTP — 发送测试邮件

```python
# 测试脚本（163/QQ 邮箱用 SMTP_SSL，Gmail 用 starttls）
import smtplib, os

with smtplib.SMTP_SSL(os.environ['SMTP_HOST'], int(os.environ['SMTP_PORT']), timeout=15) as server:
    server.login(os.environ['SMTP_USER'], os.environ['SMTP_AUTH_CODE'])
    print("SMTP 登录成功 ✅")
```

**实测结果**：
- 登录是否成功：是
- 备注：SMTP_SSL 连接 163 邮箱成功
