## 用例：AI结构化生成日报初稿
| 项目 | 内容 |
| :--- | :--- |
| 用例ID | UC‑002 |
| 用例名称 | AI结构化生成日报初稿 |
| 参与者 | 主执行者：员工
辅助执行者：私有化本地大模型 |
| 简要描述 | 系统结合采集素材与岗位模板，调用本地大模型生成结构化日报初稿，无素材禁止编造内容。 |
| 优先级 | 高 |
| 前置条件 | 已获取工作素材，本地大模型服务可连通。 |
| 后置条件 | 生成日报初稿并保存，进入编辑状态。 |
| 基本事件流（主流程） | 1.员工发起AI生成日报操作
2.系统加载岗位模板，组装提示词与工作素材
3.调用本地大模型生成日报文本
4.空话过滤后展示日报初稿 |
| 扩展/异常事件流 | 3a 大模型服务超时或者不可用
 3a‑1.系统提示AI生成失败
 3a‑2.允许员工手动编写日报
3b 不存在有效工作素材
 3b‑1.系统提示缺少素材，不生成虚假日报 |
| 包含用例 | UC‑008 私有化本地大模型调用 |
| 扩展用例 | 无 |
| 特殊非功能需求 | 业务数据不上公有云；单次生成耗时≤10秒。 |
| 备注 | 输出遵循三段式：今日完成、明日计划、风险阻塞。 |
| 维护记录 | 需求分析师｜2026‑11‑09｜初稿 |
