# 智能日报生成器 — Proposal

> 版本：v1.0 | 日期：2026-11-02 | 需求分析师：[刘千湫]

---

## 1. 项目目标（可度量）

面向企业内部员工，打造一款 AI 自动日报工具：自动抓取当日工作原始记录，按照部门固定模板生成写实、无空话的日报初稿；员工简单二次编辑即可一键提交；同时支持管理者批量查看、自动汇总全员风险，把员工写日报耗时从平均 **30 分钟压缩到 3 分钟以内**。

关键量化目标：
- 日报撰写平均耗时 ≤ 3 分钟（基线 30 分钟）
- AI 初稿人工修改字数占比 ≤ 20%
- 虚假内容次数 = 0（无数据源时 AI 禁止编造）

---

## 2. 背景

企业内部员工每日需撰写工作日报，存在五大痛点：
1. 下班时回忆"今天到底干了什么"，全靠记忆翻找
2. 工作痕迹散落在 GitHub 提交、飞书任务、群聊消息等多个平台，逐个复制粘贴
3. 忙起来必有遗漏，写进去的都是"记得住的"，不是"做了的"
4. 小组成员之间的协作成果经常谁都没写进日报
5. 每人格式不一，组长还得手工汇总成团队日报

本项目通过自动采集 + AI 生成 + 模板管控 + 批量汇总，从根本上解决上述问题。

---

## 3. 范围

### 3.1 做什么（逐条编号，供用例追溯）

**员工端功能：**
1. **多数据源自动采集**：对接飞书/企业微信聊天、Jira 任务、代码提交记录，自动拉取当日工作素材；保留手动补充入口。
2. **结构化 AI 生成**：严格遵循管理员锁定的三段式模板（今日完成 / 明日计划 / 风险阻塞）；自动过滤空话套话，禁止 AI 编造工作内容。
3. **内容编辑与版本留存**：支持人工润色；自动保存 AI 初稿 + 终稿，保留多版本快照。
4. **一键提交 + 文档导出**：一键推送至内部 OA/办公平台；支持导出 Markdown、Word 文件。
5. **岗位差异化模板**：研发/产品/运营/销售 4 套专属话术库，自动匹配岗位措辞。

**管理端功能：**
6. **模板管控**：管理员统一维护团队模板，锁定结构，员工仅可修改正文文字。
7. **全员日报批量查看**：自动提取全员阻塞项，生成团队风险汇总简报。
8. **基础数据看板**：日报提交率、逾期名单、内容缺项统计。

**安全管控：**
9. 支持私有化本地调用大模型，原始业务数据不上传公有云端；全链路操作留日志，满足审计要求。

### 3.2 不做什么（本期明确排除，逐条给出理由）

| 编号 | 排除项 | 理由 |
|------|--------|------|
| X1 | 不做周报、月报、季度总结 | 只聚焦单日日报生成，不扩展周期报表能力。v1.1 再议 |
| X2 | 不做复杂数据分析、图表生成 | 只产出纯文字结构化文本，不增加 BI 图表模块 |
| X3 | 不开放自由自定义模板结构 | 员工只能改文字，不能增删模块；不支持个人新建全新模板。保证全部门格式统一 |
| X4 | 不做对外公开的互联网 SaaS 版本 | 只做企业内部私有化部署版本，不面向外部个人用户售卖 |
| X5 | 不接入外部互联网公开数据 | 只读取企业内部业务工作记录，杜绝无关信息混入日报 |
| X6 | 不做复杂审批流 | 仅完成提交动作，不串联多级审批流程，审批沿用现有 OA 系统 |

## 4. 技术约束

| 约束项 | 要求 |
|--------|------|
| 编程语言 | Python 3.12+ |
| 包管理器 | uv |
| 数据库 | SQLite（标准库 sqlite3） |
| 运行环境 | 本地 / 内网服务器，支持私有化部署 |
| 数据凭证 | GitHub Personal Access Token（只读）、飞书开放平台凭证、SMTP 邮箱授权码。一律通过本地环境变量注入，严禁写入代码或提交到代码仓库 |
| AI 大模型 | 支持私有化本地调用，原始业务数据不上传公有云端 |
| 代码规范 | PEP 8，静态扫描（flake8/ruff）清零全部告警 |
| 版本控制 | Git，specs/ 目录与代码同库管理 |

## 5. 成功标准（可度量）

### 5.1 员工效率指标

| 指标 | 度量口径 | 目标值 |
|------|----------|--------|
| 日报撰写平均耗时 | 上线后连续两周统计均值 | ≤ 3 分钟（基线 30 分钟） |
| AI 初稿人工修改字数占比 | 修改字数 / 初稿总字数 | ≤ 20% |
| 虚假内容次数 | 无数据源时 AI 自动编造的次数 | = 0 |

### 5.2 内容质量指标

| 指标 | 度量口径 | 目标值 |
|------|----------|--------|
| 空话套话占比 | 系统自动识别虚话条数 / 总条数 | ≤ 5% |
| 格式合规率 | 严格匹配三段式模板的日报比例 | = 100% |

### 5.3 团队管理指标

| 指标 | 度量口径 | 目标值 |
|------|----------|--------|
| 日报按时提交率 | 按时提交人数 / 应提交人数 | ≥ 95% |
| 管理者汇总耗时 | 人工整理全员风险耗时（基线 20 分钟） | ≤ 2 分钟 |

### 5.4 安全指标

| 指标 | 度量口径 | 目标值 |
|------|----------|--------|
| 数据外泄事件 | 公有云端出现业务明文数据 | = 0 |
| 日志完整率 | 留存日志的生成记录占比 | = 100% |

### 5.5 非功能需求

| 项 | 指标 |
|----|------|
| 稳定性 | 每日定时生成任务成功率 ≥ 99% |
| 响应速度 | 抓取数据 + 生成日报初稿单次耗时 ≤ 10 秒 |

---

## 6. 风险说明

1. **数据源接口不稳定**：提前做好接口重试机制，抓取失败时自动提醒员工手动补充素材。
2. **AI 依然产出空话**：持续迭代话术过滤词库，持续优化 prompt 约束。

---

## 7. 术语定义

| 术语 | 定义 |
|------|------|
| 三段式模板 | 固定结构：今日完成 / 明日计划 / 风险阻塞 |
| AI 初稿 | 系统根据抓取的原始数据自动生成的日报第一版 |
| 终稿 | 员工在 AI 初稿基础上人工润色后提交的最终版本 |
| 版本快照 | 每次编辑自动保存的历史版本（含 AI 初稿 + 各次人工修改） |
| 岗位话术库 | 针对不同岗位（研发/产品/运营/销售）预设的专属措辞集合 |
| 三源核验 | 调研结论须至少两个独立可信来源相互印证 |
