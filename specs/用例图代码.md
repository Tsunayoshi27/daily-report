泳道图
@startuml 日报生成器-泳道图
|用户|
start
:手动触发日报生成;
:指定日期（默认当天）;

|主编排入口|
:接收请求，校验参数;
:按序调度各层模块;

|采集层|
fork
  :GitHubCollector\n拉取当日commit记录;
fork again
  :FeishuCollector\n拉取当日任务/消息;
fork again
  :MockCollector\n返回模拟数据(备用);
end fork
:汇总原始数据 → list[RawRecord];

|生成层|
:ReportAssembler\n按时间/项目归类;
:TemplateEngine\n套用三段式模板;
:ContentFilter\n过滤空话套话;
:生成 DailyReport 实体;

|主编排入口|
:保存日报到SQLite;
:创建版本快照;

|推送层|
fork
  :EmailPusher\nSMTP邮件发送;
fork again
  :FileExporter\n导出Markdown/Word;
end fork

|用户|
:收到邮件 / 获取文件;
:查看/编辑日报;
stop
@enduml



类图
@startuml 日报生成器-类图
left to right direction
!define table(x) class x << (T,#FFAAAA) >>
!define pk(x) <u>x</u>
!define fk(x) <i>x</i>

table(RawRecord_内存对象) {
  pk(source + timestamp) : 联合主键
  --
  source : TEXT
  timestamp : DATETIME
  project : TEXT
  title : TEXT
  detail : TEXT
  url : TEXT
  author : TEXT
}

table(DailyReport) {
  pk(id) : INTEGER
  --
  date : TEXT
  author : TEXT
  role : TEXT
  today_done : TEXT
  tomorrow_plan : TEXT
  risks : TEXT
  ai_draft : TEXT
  final_content : TEXT
  is_submitted : INTEGER
  created_at : TEXT
  updated_at : TEXT
  --
  UNIQUE(date, author)
}

table(ReportSnapshot) {
  pk(id) : INTEGER
  --
  fk(report_id) : INTEGER
  version : INTEGER
  content : TEXT
  created_at : TEXT
  --
  FK(report_id → DailyReport.id)
  UNIQUE(report_id, version)
}

RawRecord_内存对象 "N" -- "1" DailyReport : "组装\n(采集→生成)"
DailyReport "1" -- "0..N" ReportSnapshot : "版本快照"
@enduml
